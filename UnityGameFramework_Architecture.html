🟢 框架类（UGF 自带）

🔵 Unity 类（引擎原生）

  • • MonoBehaviour — Unity 组件基类
  • • Time — 游戏时间管理
  • • GameObject — 场景对象
  • • 以上由 Unity 引擎提供，框架通过 GameFrameworkBehaviour 桥接

🟢 框架类（UGF 自带）

  • • GameEntry — 框架总入口
  • • GameFrameworkComponent — 组件基类
  • • BaseComponent — 基础组件类
  • • 19个模块的 Component/Manager/Helper
  • • IUIForm, UIForm — UI 接口与抽象类
  • • IObjectPool, IAsset — 接口定义

🟣 用户实现类（需自定义）

  • • UGuiForm — StarForce 自定义 UI 基类
  • • MenuForm / SettingForm — 具体 UI 表单
  • • DialogForm / AboutForm — 对话框/关于页
  • • UpdateResourceForm — 资源更新

🟡 Procedure 流程（用户继承）

  • • Launcher → Splash → CheckVersion
  • • InitResources → CheckResources → Menu → Main
  • • 每个 Procedure 继承 Procedure 基类
  • • 实现 OnEnter / OnUpdate / OnLeave

添加 Component 清单

  • ① 创建 Component 类（继承 GameFrameworkComponent）
  • ② 创建 Manager 类（封装模块业务逻辑）
  • ③ 创建 Helper 类（可替换的实现细节）
  • ④ 在 GameFramework.prefab 中添加组件
  • ⑤ 实现 OnAwake/OnStart/OnUpdate/OnDispose

添加 Component 代码模板

  • public class MyComponent : GameFrameworkComponent
  • protected override void OnAwake()
  • protected override void OnStart()
  • protected override void OnUpdate(float dt)
  • GameEntry.AddComponent(new MyComponent())
